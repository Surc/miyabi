# 多版本与分段导出

同一番号继续共用影片资料；导出不再根据文件数量自动生成 CD 序号。原生刮削和 MDCz 增强共用这套规则。

## 命名规则

- 一个完整视频沿用 `番号.strm`。
- 多个完整版本使用 `番号 - 属性 [稳定标识].strm`。属性取文件名中的分辨率、剪辑版本和中字标记；LTX、RESTORED 保留为原始标记，不推断其含义。稳定标识区分同属性的不同文件，不依赖扫描顺序。这符合 [Emby 多版本命名规则](https://emby.media/support/articles/Movie-Naming.html)。
- 明确的 CD、DISC、DISK、DVD、PART、PT 标记保留实际分段序号，支持前导零，不将 CD2、CD10 重编号为 CD1、CD2。
- A/B、末尾数字，以及紧贴番号的 A/B/C/D，需要同目录、同主体名称、同扩展名与从 1 开始的完整序列才作为分段。单独的 C、带分隔符的 `-C` 和不完整字母序列仍是完整版本。
- 同一分组的显式分段标记出现重复段号时，在写入前报错，要求用名称或目录区分版本。含重复字母的推测序列不成立，保留为独立完整版本。
- 完整版本与分段共存，或存在多套分段时，每个版本使用独立子目录，分别写入 NFO 和图片。Emby 的分段堆叠要求目录内没有其他版本，这种布局不承诺自动合并为同一张多版本卡片。

## 播放、字幕与清理

播放入口只查询实际生成文件的精确路径，优先完整版本，再按分段序号选取。Emby 只索引合并后的主版本时，继续检查其他导出路径；返回路径必须属于当前影片的实际导出文件。

字幕任务按完整版本建立目标，独立保存和复用字幕，并限制版本匹配。真正的分段不套用整部影片字幕。导出名称变化时，使用旧 STRM 中的视频文件 ID 搬移已生成的字幕，不根据旧 CD 排序猜测归属；目标已有不同内容时报错。扫描多个视频的目录时，不再将唯一字幕作为其他版本的兜底字幕。

先写出全部新资源和 STRM，再清理旧导出。清理只匹配 Miyabi 的精确命名、版本子目录及对应生成字幕，保留自定义文件、相似前缀文件和符号链接。番号纠正使用相同规则清理旧目录。

现有资料与图片可以通过本地重新导出修复，无需重新请求元数据。代码更新本身不会自动修改 NAS 上的现有导出。
