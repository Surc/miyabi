# 字幕下载设置

入口为「设置 → 字幕下载」，与订阅磁力的字幕偏好独立。默认保持现有行为：自动下载开启，迅雷、SubtitleCat、AVSubtitles 全部开启，简体优先。

配置保存在数据库的 `subtitle.config`，无需迁移或新增依赖。保存后影响后续字幕任务；正在执行的任务使用开始时读取的配置快照。

## 开关与语言偏好

- 总开关控制自动获取外置字幕；关闭后保留已下载文件，既有字幕路径维护继续执行。
- 关闭的字幕源不发起搜索请求。全部来源关闭时不自动下载，手动测试入口会提示至少启用一个来源。
- 简体优先、繁体优先调整已知语言候选的排序，不排除另一种中文，不进行简繁文字转换。原有番号、版本匹配、格式排序和最多三条导出规则继续生效。
- 默认值由后端统一提供。首次使用或配置中缺少字段时补齐默认值，明确保存的 `false` 不会被重新开启。

## 测试下载

输入番号后，后端按页面上的配置快照实际搜索、下载并校验一个可用字幕。测试结果显示来源、名称、简繁语言、格式、文件大小、候选数量和用时；无匹配与检索/下载失败分别显示，来源错误可以展开查看。

总开关关闭时仍可手动测试。测试不会保存配置、创建媒体库字幕记录或写入导出目录。网络阶段总时限为 90 秒，最多尝试八个候选；沿用全局代理、Fake-IP 处理、URL/私网校验、重定向与大小限制、编码转换及时间轴校验。AVSubtitles 的匿名会话、倒计时和 ZIP 处理同样适用。

## 接口

接口位于既有鉴权及同源检查下，响应使用 `no-store`：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/settings/subtitles` | 读取配置 |
| `PUT /api/settings/subtitles` | 保存配置，返回保存后的值 |
| `POST /api/settings/subtitles/test` | 实际检索与测试下载 |

配置完整格式：

```json
{
  "enabled": true,
  "sources": { "xunlei": true, "subtitlecat": true, "avsubtitles": true },
  "language": "zh-CN"
}
```

`language` 支持 `zh-CN`、`zh-TW`。更新应发送完整配置，省略字段时使用默认值，不与先前保存的配置合并。

整个配置为 `null` 时返回 HTTP 400，不会重置已保存的开关。

测试请求为 `{"code":"SSIS-589","config":{...}}`，其中 `config` 可以省略，省略时读取已保存配置。番号长度上限为 128，后端解析和校验番号；文件名中的无码/流出标记也用于匹配版本。结果状态为 `downloaded`、`not_found`、`failed`；无匹配和来源失败返回结构化结果，非法输入返回 HTTP 400。
