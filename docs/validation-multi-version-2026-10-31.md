## 验证边界

导出、Emby、刮削、字幕、扫描、媒体库、应用装配及 API 八个 Go 包回归通过；此前前六包竞争检测通过。原生配置和进程管理等 17 项测试、实际打包内容检查、HTTP 登录及静态资源检查、真实子进程停止/启动和令牌保留检查通过。使用现有工具链和离线缓存，没有安装依赖。
