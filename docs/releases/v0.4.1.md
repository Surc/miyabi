Miyabi v0.4.1 修复 Emby 直接播放的路径兼容、缓存过期和异常响应处理，面向 Intel J4125 / linux/amd64。

## 修复

- 播放路径支持 `/` 根目录、Windows 盘符和 UNC 共享路径，正确处理明确等价的正反斜线；保留目录和文件名大小写，避免误选资源。
- 安卓详情页可见时每 30 秒检查播放目标，返回前台或网络恢复时重新检查；获取中、失败和过期链接不可启动。点击时再次检查过期状态，保留正常链接的同步外部应用唤起。
- 播放专用 HTTP 客户端限制 JSON 响应为 1 MiB，不把 Emby 错误正文回传给前端；保留错误分类、12 秒超时和跨源重定向拦截。
- 服务器地址支持 `/emby` 前缀和末尾斜线，并明确拒绝含账号、查询参数或片段的基址。

沿用现有设置、STRM 文件和旧 Emby 通知映射，无需重刮或重建资料。多文件影片仍默认首个生成视频文件，重复且不同 ID 的媒体库目标仍报错；不按标题猜测，也不承诺自动连播。

## 获取

```sh
docker pull ghcr.io/surc/miyabi:v0.4.1
docker pull ghcr.io/surc/miyabi-mdcz:v0.4.1
```

仅发布 linux/amd64。MDCz 仍为可选独立服务，固定引擎 `f65e7d4161151aff1531f3b99872e49234d5d539`；本版未修改其配置或实现。

附件 `miyabi-native_0.4.1_linux-amd64_preview.fpk` 为原生 FPK 预览包，另有 `SHA256SUMS` 与 `miyabi-native_0.4.1_bundle.json`。安装不需要 Docker/Electron，不在线下载依赖；打包结构和数据迁移约定沿用 v0.4.0，详见 [原生包说明](https://github.com/Surc/miyabi/blob/v0.4.1/docs/fnos-native-package.md)。
