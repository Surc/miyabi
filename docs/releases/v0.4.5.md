Miyabi v0.4.5 集成 v0.4.2 之后的原生启动、PC 播放入口、评分同步、详情排版与发现分页修复，面向 Intel J4125 / linux/amd64。

## 修复

- 修复 fnOS 原生应用进程身份检查错误，解决启动时的 `read is not a function`，保留既有进程归属检查和启停保护。
- PC 端的 Emby 播放入口打开对应影片的 Emby 网页；Android 继续使用 Emby App 播放链接。网页播放需先配置 Emby 连接，并在 Emby 网页登录。
- 发现卡片直接复用已经读取的详情评分；列表缺少评分时，不再将其缓存成已确认的空分，也不会覆盖已知详情评分。旧 JavDB 评分缓存自动重新验证。
- 详情区的发行日期、片长和评分标签保持单行；JavLibrary 重试按钮紧邻状态，窄屏可横向滚动。
- 预加载 6 页后，底部显示可直接点击的 1–6 页；第 6 页仍可继续点下一页加载后续内容。来源不足时显示实际页数。

## 可选 JavLibrary 评分服务

合入 PR #13 的独立 Javinizer 评分适配器，默认关闭。评分与评论分别请求、缓存和重试；JavDB/FANZA 的来源和分制保持各自语义。

FPK 包含 Miyabi 适配代码，不包含 Javinizer 引擎、FlareSolverr 或浏览器，也不会自动启动这些服务。现有 MDCz 引擎固定版本保持 `f65e7d4161151aff1531f3b99872e49234d5d539`。有意启用时需按[独立评分服务文档](https://github.com/Surc/miyabi/blob/v0.4.5/docs/javinizer-rating-extension.md)另行部署固定引擎。

真实 JavLibrary 真人验证、真实评分/评论和 NAS 上的可选服务尚未验收。本版不宣称解决站点的人机验证或自动恢复 JavLibrary。

## 安装与升级

附件 `miyabi-native_0.4.5_linux-amd64_preview.fpk` 为 fnOS 原生预览包，另附 `SHA256SUMS` 和 `miyabi-native_0.4.5_bundle.json`。使用 fnOS 应用中心手动安装或升级，并保留应用数据。

不需要重刮或重建资料库。沿用既有设置、数据库、图片缓存和 STRM；旧空评分会按新的评分缓存规则重新读取。已改用 18081 的安装继续使用该端口；新装时可在安装向导填写可用端口及对应访问地址。

同时提供 linux/amd64 镜像：

```sh
docker pull ghcr.io/surc/miyabi:v0.4.5
docker pull ghcr.io/surc/miyabi-mdcz:v0.4.5
```
