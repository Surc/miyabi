# Miyabi 0.4.13 原生预览包

本版将此前分别构建的功能和当前全部本地源码修改合入同一主干提交，再重新构建前端与 Linux amd64 程序。包内 `bundle.json` 的 `source_revision` 对应本次主干提交，程序保留干净构建的 VCS 信息；不再以旧功能快照替换单个二进制。

## 主要变化

- 字幕下载设置：总开关、迅雷 / SubtitleCat / AVSubtitles 来源开关、简繁偏好和实际测试下载。默认行为保持开启全部来源、简体优先；手动测试不修改媒体库或保存配置。
- 字幕安全与兼容：支持 Fake-IP DNS，保留私网、重定向、连接固定、大小及内容检查；详情失败不掩盖其他来源结果，关闭自动下载时保留已有字幕。
- 多版本与真正分段导出：完整版本使用稳定的独立名称或目录，保留 CD 和连续 A/B/C 分段规则；版本字幕、STRM 改名与数据库路径同步，兼容重复导出和既有本地别名。
- JavLibrary 评分：原生指纹客户端、合法无评分页面和静态详情地址兼容；可选 PC 人工验证会话通道及其原生配置继续保留。
- 发现列表缓存预加载、评分空值展示、磁力字幕标记及 SQLite 写竞争重试调整。
- 原生服务支持外部 MDCz 与浏览器通道配置，普通升级复用原配置和数据，实际卸载及手动备份沿用已有备份机制。

使用已有 Go、Node、前端依赖及已校验的 0.4.12 包内运行时、桥接、字体和 CA，不安装新依赖。MDCz 引擎继续固定为 `f65e7d4161151aff1531f3b99872e49234d5d539`。

合入前完成 Go 全量回归、前端 47 文件 / 302 测试、TypeScript、前端生产构建、Node 原生服务 / 浏览器通道 / 桥接 37 项测试，以及 Python 包格式 4 项测试。

包内启动检查会实际运行随包程序和原生模块，并核对 HTTP 提供的设置资源与本次前端构建完全一致；同时验证字幕设置接口、持久化、非法输入及测试快照不改写配置，防止源码合入后安装包遗漏界面。

该产物供原生应用升级使用；本次出包不代表已部署到 NAS。真实浏览器交互、人工验证会话、媒体播放和升级后的设备验收由用户完成。已有 Docker MDCz 与 PC 会话服务不随 FPK 重新部署，连接参数继续从原有安装配置读取。
