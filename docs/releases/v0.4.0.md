Miyabi v0.4.0 面向 Intel J4125 / linux/amd64，包含播放 PR #6、MDCz 与卡片 PR #7。扩展保持独立模块与可追踪的挂载点，保留原 API。

## 本版改动

- 已入库卡片封面左下角显示中文、中文破解、破解、流出等实际文件版本；未知不猜测，无码不当破解，不跨文件合成属性。
- 移除列表独立 loading/补齐区域，改为卡片加载状态；保留暂停/继续/重试、可配置六页预加载、字幕筛选和仅当前页下载图片。
- 新增默认关闭的 MDCz 增强、统一来源/代理/翻译配置、影片介绍、真实海报角标和 NFO/Emby 资源标签；保留原图及离线导出。MDCz 固定 `f65e7d4161151aff1531f3b99872e49234d5d539`，不自动跟随 latest。
- Android Emby 3.4.26+ 详情页直接播放入口，按准确 STRM 映射路径定位；其他平台不伪装成可直接开播。作品名称增加番号，修复字幕筛选负命中、部分刷新、播放目标缓存和标题去重问题。

## Docker

仅发布 linux/amd64；旧 v0.3.0 的双架构标签保留。

```sh
docker pull ghcr.io/surc/miyabi:v0.4.0
docker pull ghcr.io/surc/miyabi-mdcz:v0.4.0
```

普通 Miyabi 升级继续使用原数据目录、端口及访问配置。MDCz 为可选独立服务：默认不开启，需配置回环或私有网络连接及独立密钥；不能仅拉取主镜像就假定已内置桥接。部署参数与数据备份见 `docs/mdcz-extension.md`。

## 原生 FPK 预览包

附件 `miyabi-native_0.4.0_linux-amd64_preview.fpk` 包含 Miyabi、MDCz 桥接、Node 24、生产原生依赖、中文字体和 CA，安装时不下载依赖、不需要 Docker/Electron。安装后在 Miyabi 设置中开启 MDCz 增强。

这是首个原生预览包，尚未完成用户 J4125/fnOS 上的安装、升级、卸载、ACL、字体/TLS 和 Emby 实机验收。manifest 的 fnOS 1.0.0 是候选声明基线，不是已实测的最低兼容版本。建议先用新数据目录验收，勿直接替换唯一生产实例。旧 Docker 数据不会自动迁移；先备份，保留 STRM 地址/令牌，并按 `docs/fnos-native-package.md` 停服迁移。

附件另含 `SHA256SUMS` 和 `miyabi-native_0.4.0_bundle.json`，记录应用 Git SHA、MDCz SHA、Node 版本及包内文件哈希。源码为本 Release 的 Source code；MDCz 对应源码见 https://github.com/ShotHeadman/mdcz/tree/f65e7d4161151aff1531f3b99872e49234d5d539 。构建入口为 `packaging/fnos/build-release.sh`。

## 验证范围

前端 251 测试、Go 37 个测试包（大语料超时后分组补跑）、相关 race、Node 36、Python 3 和固定 MDCz runtime 4 项通过。发布流程执行生产构建、实际程序启动/鉴权/内嵌网页/原生依赖检查、FPK 打包及镜像推送，全部成功后公开本 Release。

真实站点评分/评论、翻译账号、浏览器和 NAS/Emby 仍需环境验收；JavLibrary 原有网络问题未在本版宣称修复。详细记录见 `docs/validation-2026-10-23.md` 与 `docs/release-v0.4.0.md`。
