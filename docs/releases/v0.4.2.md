Miyabi v0.4.2 为 JavLibrary 独立评分和评论增加请求诊断，面向 Intel J4125 / linux/amd64。

## 改动

- 失败日志区分搜索、详情、评论，以及 DNS、代理连接、TLS、超时、HTTP、重定向、异常页面、身份和评分格式等原因。
- 记录实际选择的应用内代理，将代理 CONNECT 状态和站点 HTTP 状态分开，补充重定向拒绝原因、正文长度、耗时及不含正文的页面结构摘要。
- 底层错误链保留，日志只输出允许的诊断字段，防止相对跳转地址或畸形响应头中的令牌泄漏；对外仍返回原有通用 502。
- 识别明确的维护/挑战页，未知 HTML 保留为未知页面；已有空评分、空评论、抓取路径、选择器、JavLibrary 原始 10 分制和缓存约定保持原样。

本版未修改 JavDB/FANZA、自动下载、前端或 MDCz 实现。不需要重刮或重建资料，沿用既有设置、数据库、缓存与 STRM 文件。

## 获取

```sh
docker pull ghcr.io/surc/miyabi:v0.4.2
docker pull ghcr.io/surc/miyabi-mdcz:v0.4.2
```

仅发布 linux/amd64。附件 `miyabi-native_0.4.2_linux-amd64_preview.fpk` 为原生 FPK 预览包，另附 `SHA256SUMS` 和 `miyabi-native_0.4.2_bundle.json`。固定 MDCz 引擎仍为 `f65e7d4161151aff1531f3b99872e49234d5d539`。

## 验证与使用

JavLibrary、netx、catalogue、API 四包 Go 回归及 race 检测通过，各 414 个测试/子测试通过事件；格式和差异检查通过。发布流程执行生产构建、真实产物 smoke、FPK 打包和镜像推送，全部成功后公开 Release。详见 [回归记录](https://github.com/Surc/miyabi/blob/v0.4.2/docs/validation-javlibrary-v0.4.2.md)。

通过 Miyabi 的已保存网络代理配置、一次独立评分/评论请求及对应请求 ID 日志进行验证；步骤见 [JavLibrary 请求诊断](https://github.com/Surc/miyabi/blob/v0.4.2/docs/javlibrary-diagnostics.md)。默认等级记录错误，debug 可额外查看脱敏页面结构摘要。

真实站点的评分/评论分页与 NAS 路径仍需环境验收；本版不宣称第三方来源已经恢复。原生 FPK 保持 preview，尚未完成用户 J4125/fnOS 安装升级及字体/TLS/ACL 实机验证；未部署或迁移 NAS 数据。
