# 入库版本卡片与加载状态（2026-10-23）

媒体库卡片和发现/搜索预加载列表的已入库卡片，在封面左下角显示当前库实际文件的版本，例如“中文”“中文破解”“破解”“流出”。这是独立的只读扩展，不依赖开启 MDCz，不重刮、不写图片、不改数据库或旧 API。

## 判定与显示

- 从索引中读取当前挂载账号/目录及本地库的实际文件名，范围与媒体库列表相同。已有文件立即可用，无需重建；文件名不含可识别标记时不显示版本，不能据网络磁力猜测已入库版本。
- 中文沿用 `magnet.Infer` 的字幕规则；破解沿用其破解规则并识别独立 `UMR` 标记。明确的“流出”/`leaked` 优先独立显示。`无码` 不当作 `破解`，因此也可能显示“无码”“中文无码”“中文流出”。这些是文件名推断，不是媒体内容检测。
- 同一文件同时满足中文和破解才显示“中文破解”。一部影片拥有单独中文文件和单独破解文件时显示两个标签；有无法识别的文件时在提示中说明。重复标签去重，顺序稳定，不跨文件合成属性。
- 发现页原有下方“中文字幕/破解”提示仍表示网上的磁力资源，与封面左下角的入库版本含义不同。只有共享入库状态确认 `in_library` 后才请求版本。
- 移除预加载独立补齐/进度区域。当前页资料未到时显示卡片骨架及“加载中”；磁力未确认的卡片显示加载/暂停/重试状态，评分加载显示小转圈。完成后卡片加载状态消失。工具栏只保留小型暂停/继续/重试按钮。
- 默认六页及配置、筛选后继续补齐逻辑保持；未打开页面仍不下载图片。浏览器验收由用户完成，本轮仅自动化/SSR 验证。

## 可选接口与接入点

`POST /api/extensions/library/resource-versions` 接受 `{"ids":[1,2]}`，最多 100 个正整数、请求体最多 8 KiB，复用鉴权/同源检查并返回 `no-store`。响应仅包含 `id/available/labels/unmarked`，不泄露文件名、路径或账号。不存在或当前库无文件时返回 `available:false`、空标签。重复 ID 合并；无标记不等于不存在。

```json
[{"id":1,"available":true,"labels":["中文破解"],"unmarked":false}]
```

| 模块 | 职责 |
| --- | --- |
| `internal/library/resource_versions.go` | 一次批量只读文件查询、当前库范围、逐文件判定 |
| `internal/api/library_versions_extension.go` | 可选窄接口、校验、响应；旧 LibraryManager 不增加方法 |
| `web/src/api/library-versions.ts` | 卡片请求合批、最多 100、取消后丢弃响应、按账号/目录隔离查询键 |
| `web/src/components/movie/library-version-badge.tsx` | 左下角标签及加载状态、发现页入库状态桥接 |
| `web/src/features/discover/extensions/cached-results.tsx` | 已有扩展内的卡片加载、空位骨架与紧凑操作 |

原文件仅在 `internal/api/router.go` 增加一行可选路由注册，在 `web/src/features/library/movie-card.tsx` 使用原 `coverOverlay` 插槽挂载组件；不修改通用 MovieCard。批量读取不会逐卡抓取媒体库详情或远端磁力。

查询键属于现有 `library` 前缀，复用任务完成、重刮和来源切换的失效机制。账号/目录也是键的一部分；切换期间的晚到响应不能覆盖新库。重新挂载会读取最新版本，刷新时暂隐藏旧标签。失败不伪装为某种版本，也不妨碍打开详情。

## 升级与回归

同步上游时核对 `libraryScope`、`File.Name/MovieID`、字幕/破解识别、共享入库状态及 `library` 查询失效约定；仅在自有适配器调整，保持旧接口不变。移除扩展时去掉两个挂载点和发现扩展的覆盖层即可，不需要数据库回滚。

测试覆盖文件名分类、局部范围、重复/未知 ID、多副本不误合成、鉴权/上限、合批/取消/缺失响应、来源切换晚到响应、标签位置、刷新隐藏旧值、卡片骨架不请求图片及六页只渲染当前页。结果见 [本轮验证记录](validation-2026-10-23.md)。
